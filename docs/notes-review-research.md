# Notes-review research basis

Checked 25 October 2026 against official product documentation and Kenya Law.

## Product fit

- **Gemini Notebook (NotebookLM)** is the strongest free fit for questions grounded in a student's uploaded notes: its free Standard plan includes 100 notebooks and 50 sources per notebook. It analyzes the supplied source collection; it is not a substitute for primary Kenyan legal sources or a complete current law service. Official limits: https://support.google.com/gemininotebook/answer/16213268?hl=en
- **Perplexity** is useful for cited open-web discovery; its official documentation says answers link numbered citations and free users receive a limited number of Pro Searches per day. Search citations still need to be opened and checked against the actual official judgment or statute. Official description: https://www.perplexity.ai/help-center/en/articles/10352895-how-does-perplexity-work
- **Kenya Law** is the primary source selected for verification in this application. The National Council for Law Reporting describes it as the official source of Law Reports and consolidated Kenyan laws and exposes case law, legislation, and Gazette materials: https://kenyalaw.org/

## Accuracy limit

Do not advertise the review as 100% accurate. Stanford Law School's 2025 empirical evaluation reported that the tested commercial legal research tools hallucinated more than 17% of the time, even though they performed better than general-purpose GPT-4: https://law.stanford.edu/publications/hallucination-free-assessing-the-reliability-of-leading-ai-legal-research-tools/

## Implementation decision

Use AI to identify legal questions and candidate authorities, query/open official Kenya Law records, then have the AI produce corrected notes with explicit source links and an authority-check status. A citation is only called verified if the official record was opened and readable. Never turn a search-result title alone into proof of a holding, never invent replacement authorities, and show unresolved matters as requiring student or lecturer review. Preserve the uploaded/original notes separately from the corrected editable version. Sharing the corrected notes to the common Library is an explicit student action.


## Integration options checked 25 October 2026

- **Consumer NotebookLM remains a user-operated companion, not an app backend.** Google now documents a Gemini Notebook Enterprise REST API in Preview for notebook create/get/list/delete/share and source ingestion. It requires Google Cloud project/IAM setup and NotebookLM Enterprise licensing. The documented API pages reviewed cover notebook/source management, not a general-purpose notebook Q&A endpoint. The licensing guide describes a 14-day trial and paid subscriptions; the standard subscription minimum is 15 seats. This is not a sustainable free integration for Group 13. Official docs: https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks ; https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks-sources ; https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/set-up-licensing
- **Gemini API Google Search grounding is the best low-cost platform-native experiment.** The current Gemini API supports tool-grounded responses with structured URL-citation annotations tied to answer spans. Google documents 5,000 free Google Search queries per month shared across Gemini 3+ models, then $14 per 1,000 queries; an individual prompt can cause multiple billed searches. This is not equivalent to unlimited free research, and the app must capture citation metadata rather than flattening the answer text. Official docs: https://ai.google.dev/gemini-api/docs/google-search ; https://ai.google.dev/gemini-api/docs/pricing
- **Perplexity recommends its Agent API for new applications, not the older Sonar Chat Completions path.** Its Agent API can search the web and fetch known URLs, returns structured search-result items and source URLs, and supports effort levels. The official pricing page charges by model tokens plus tool calls; web search is $2.50/1,000 standard invocations or $1/1,000 fast, and fetch_url is $0.50/1,000. This is API-billed, not included in the consumer free plan. Perplexity's migration guide says Sonar chat-completions support ended September 27, 2026. Official docs: https://docs.perplexity.ai/docs/sonar/quickstart ; https://docs.perplexity.ai/docs/agent-api/tools/web-search ; https://docs.perplexity.ai/docs/agent-api/tools/fetch-url-content ; https://docs.perplexity.ai/docs/getting-started/pricing
- **Recommended LLB13 architecture:** keep Kenya Law as the authority-of-record and the existing owner-scoped upload/review process. Optionally use Gemini Search grounding or Perplexity Agent API only for discovery of neutral legal questions and candidate sources. Restrict searches to Kenya Law or other explicit official legal domains, retain their returned source IDs/URLs and dates, fetch official judgments/statutes through the existing Kenya Law service, and only then pass the opened text to the correction model. A provider search snippet/citation alone must never flip an authority to verified. Do not send a student's full notes to a third-party discovery API by default; send extracted neutral search phrases, disclose provider/data handling, and make any broader document-based external research opt-in.
- **Gemini Deep Research is technically capable but not a free default for this workflow.** The current API agent supports asynchronous multi-step research, collaborative planning, Google Search/URL Context and citations. Google's pricing guide estimates roughly $1–$3 for a moderate task and $3–$7 for the Max variant, with costs varying by agentic search/token use. Reserve it for an explicitly requested, budget-confirmed deep-dive rather than automatically running it on every note upload. Official docs: https://ai.google.dev/gemini-api/docs/deep-research ; https://ai.google.dev/gemini-api/docs/pricing

- **Citation-update fixture checked against the opened official judgment:** Kenya Law identifies *Matemu v Trusted Society of Human Rights Alliance & 5 others* (Civil Application 29 of 2014) as `[2014] KESC 6 (KLR)` and includes the neutral citation in the judgment header. The regression test uses that official format to ensure a corrected citation is surfaced with its source ID, while remaining a mocked AI response rather than a live provider-generated correction. Primary record: https://kenyalaw.org/akn/ke/judgment/kesc/2014/6
