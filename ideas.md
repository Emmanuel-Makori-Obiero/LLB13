# Group 13 Hub — design brief

## Chosen direction

### Theme Name
**The Reading Room**

A quiet, editorial law-school workspace inspired by annotated casebooks, not a generic productivity dashboard.

### Design movement
Contemporary editorial interface: restrained, typographic, tactile through paper-toned surfaces and fine rules rather than decorative illustrations.

### Core principles
- Make the next academic action obvious without flooding the screen.
- Treat content as serious working material: headings, metadata, deadlines, and source labels matter.
- Use cards as containers for real information, not as decorative tiles.
- Prefer horizontal structure, rows, timelines, and side-by-side reading layouts over circles and oversized widgets.
- Keep visual emphasis scarce: oxblood for action, sage for completion, muted amber for attention.

### Color philosophy
Warm ivory canvas (#F7F5F0), ink-black type (#1F2320), deep forest (#163A34) for navigation and institutional accents, oxblood (#8F3E32) for primary action, clay (#C96E52) for secondary emphasis, pale moss (#DCE7D9) for confirmed progress, and graphite borders (#D7D5CC). No gradients.

### Layout paradigm
A fixed, narrow left rail for identity and navigation; a wide content canvas with an editorial masthead, a focused “next up” block, a two-column work area, and dense but breathable list rows. Responsive collapse turns the rail into a top bar and preserves the reading hierarchy.

### Signature elements
- A small G13 monogram built from two offset bracket forms as the brand mark.
- Thin horizontal rules and section labels in small caps.
- A “next up” module that reads like a docket entry.
- Quiet status chips with text and a tiny square marker, never floating bubble graphics.
- Date stamps and “source” metadata used consistently across units, materials, and discussions.

### Interaction philosophy
Direct manipulation with visible context. Tabs are text-first. Search and filters reveal real records. Buttons have clear verbs. Inline feedback is calm and local. Empty states explain what belongs there and why.

### Animation
Subtle 150–220ms fades and horizontal translation for navigation state; no bouncy motion, parallax, or decorative loaders.

### Typography system
Display: Fraunces, a literary serif with a practical editorial feel. UI and body: DM Sans, compact and legible. Small caps labels use DM Sans with tracked uppercase. Use a tight scale: 12 / 13 / 15 / 18 / 24 / 34 / 48.

### Brand essence
Group 13 is a dependable shared desk: serious about law, generous with context, and easy to return to after a long day.

### Brand voice
Clear, warm, and specific. “Review Constitutional Law I” is better than “Continue learning.”

### Wordmark / logo
Wordmark: **GROUP 13** with a two-bracket monogram. The identity should work in monochrome and at 24px.

### Signature brand color
Deep forest #163A34.

### Asset decisions
This is a functional academic workspace, so the product uses a custom flat project icon/monogram and no decorative hero imagery. The brand icon is the only generated visual asset; content is represented through real metadata, document labels, and typography.
